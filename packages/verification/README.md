# @u-net/verification

Browser-safe helpers for public verification catalogs, hosted verifier sessions, and miniapp discovery.

```bash
npm install @u-net/verification@next
```

```ts
import { createVerificationSession, pollVerificationResult } from '@u-net/verification';
```

See [docs.egress.live](https://docs.egress.live) for guides and the versioned API reference.
