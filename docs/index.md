# U-net SDK

The canonical SDK and reference for Sovereign Core V2. Providers own their accounts, sessions, credential delivery, and inbox records. U-net supplies discovery, verification governance, Ledger V2 access, and opaque messaging transport.

```bash
npm install @u-net/server @u-net/client
```

Start with [Direct Login V2](/quickstarts/sign-in-with-unet), then use the generated [API reference](/api/generated/README) for the exact installed surface.

U-net SDK helps websites add QR-based U-net login and attestation verification without collecting passwords, emails, phone numbers, public U-net IDs, holder IDs, FCM tokens, or private keys.
